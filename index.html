01 / The benchmark

Small signals.
Long histories.

Useful personalization starts with a pattern the user may never state as a rule.

HABIT-Bench combines dialogue-derived task seeds with controlled latent habit graphs to construct real-prompt-seeded synthetic lifelines. Each probe asks the agent to choose a context-appropriate action from four alternatives.

The histories are synthetic—not longitudinal logs of real users. Each probe has one deterministic gold choice.

What does a useful memory need to do?

Diagnostic coverage follows each domain’s annotations.

01

Induce a habit

Combine repeated weak observations into a supported behavioral default.

02

Respect the boundary

Recognize when a familiar pattern falls outside the current context.

03

Retain exceptions

Apply a local override without turning it into a permanent preference.

04

Track change

Resolve which habit state was valid at the relevant point in time.

05

Check the evidence

Distinguish endorsed behavior from suggestions and nonbinding evidence.

06

Personalize selectively

Withhold unsupported personalization while keeping error types distinct.

A shared decision.
