# HABIT-Bench

Project website for **HABIT-Bench: Evaluating Habit Induction from Longitudinal Weak Evidence in Agent Memory**.

[Project website](https://hollyming.github.io/habit-bench-site/)

This repository contains the static project page. Paper and dataset release links will be added when available.

## Local preview

From the directory containing `index.html`:

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

Open http://127.0.0.1:4173. No package installation or database is needed. Google Fonts is optional; system fonts are used if unavailable. No analytics are installed.

## Evidence

Experiment results are **document-reported**. Source commits, document hashes, dataset identities, and limitations are recorded in `evidence.json`. The context-switching example is an authored illustration, not an evaluation item.

The page includes all fifteen non-oracle rows from the Qwen3-235B-A22B comparison: eight memory methods, five retrieval baselines, and two evaluator controls. The 25% line is a theoretical uniform-choice reference. Source code is available through the [anonymous repository](https://anonymous.4open.science/r/iclr27_hb_anonymous/README.md). The manuscript source link points to a private research repository and requires access.

Numerical content is generated by `scripts/generate_website_data.py` in the separate writing repository from its local dataset manifest and the designated experiment result document. The generated `data.js` and `evidence.json` are self-contained; serving this site requires neither the research repositories nor their raw data.

## Deployment

GitHub Actions publishes changes to `main` at https://hollyming.github.io/habit-bench-site/. The repository uses **Settings → Pages → Source → GitHub Actions**.

The workflow stages only `index.html`, `styles.css`, `app.js`, `data.js`, `evidence.json`, and `.nojekyll`.

## Files

- `index.html`: benchmark narrative and page structure.
- `styles.css`: responsive layout and visual design.
- `app.js`: scenario and result interactions.
- `data.js`: generated dataset statistics and experiment values.
- `evidence.json`: source provenance and claim boundaries.
- `.github/workflows/pages.yml`: automated GitHub Pages deployment.
